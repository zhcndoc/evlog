## 值得了解的三个数字

每个数字都在同一个 checkout 请求上测得，每个页面都会展示其背后的运行结果。

- **每个请求约 3µs** 的 CPU 开销，而数据库查询需要 1-50ms。[性能](/reference/performance) 会指出其他日志记录器更快的路径。
- 与承载相同请求信息的四行日志相比，**字节数减少 56%，事件数减少 75%**。[日志成本](/reference/cost) 会根据你自己的流量计算相应费用。
- **约 6.3 kB gzip 大小且没有运行时依赖**，因此你无需在记录日志前先审查依赖树。
