## 值得了解的三个数字

每个数字都在同一个 checkout 请求上测得，每个页面都会展示其背后的运行结果。

- **测量你实际部署的配置。** [性能](/reference/performance) 分别说明构建、序列化和传输成本，并记录比较套件的限制。
- **比承载相同请求的四行日志少 56％ 的字节数和 75％ 的事件数**。[日志成本](/reference/cost) 会根据你自己的流量计算其价格。
- **约 6.3 kB gzip 压缩后大小且零运行时依赖**，因此你可以直接记录日志，无需先审查依赖树。
