代理依据训练数据回答 evlog 问题时，所用信息可能比你安装的软件包落后一个版本。文档 MCP 服务器会提供最新页面。在编辑器中添加 `https://www.evlog.dev/mcp` 即可使用：无需账户或密钥，只读，并通过[流式 HTTP](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports#streamable-http)通信。

## 在编辑器中添加

### Cursor

[添加到 Cursor](https://www.evlog.dev/mcp/deeplink)会打开 Cursor，并预填服务器配置。每个文档页面顶部的复制菜单中也有相同链接，名称为**添加 MCP 服务器**。

如需手动添加，请在项目中创建 `.cursor/mcp.json`，或者创建 `~/.cursor/mcp.json` 以供所有项目使用（参见 [Cursor MCP 文档](https://cursor.com/docs/mcp)）：

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "evlog": {
      "url": "https://www.evlog.dev/mcp"
    }
  }
}
```

### Claude Code

```bash [Terminal]
claude mcp add --transport http evlog https://www.evlog.dev/mcp
```

添加 `--scope user` 可让所有项目都能使用此服务器（参见 [Claude Code MCP 文档](https://code.claude.com/docs/en/mcp)）。

### VS Code

[在 VS Code 中安装](https://www.evlog.dev/mcp/deeplink?ide=vscode)，从命令面板运行 **MCP: Add Server** 并选择 HTTP；也可以将配置提交到 `.vscode/mcp.json` 供团队使用（参见 [VS Code MCP 文档](https://code.visualstudio.com/docs/agent-customization/mcp-servers)）：

```json [.vscode/mcp.json]
{
  "servers": {
    "evlog": {
      "type": "http",
      "url": "https://www.evlog.dev/mcp"
    }
  }
}
```

### 其他客户端

将支持流式 HTTP 的 MCP 客户端指向 `https://www.evlog.dev/mcp`。在浏览器中打开该 URL 会返回此页面。

## 工具

三个工具都是只读的，也不会读取你的项目：它们只接受文档路径或你传入的数字。

| 工具 | 返回内容 | 输入 |
| --- | --- | --- |
| `list-pages` | 所有文档页面的标题、路径、描述和 URL | 无 |
| `get-page` | 单个页面的完整 Markdown，与 `/raw/<path>.md` 返回的字节相同 | `path`，例如 `/start/installation` |
| `estimate-log-cost` | 使用 evlog 前后一个月的日志事件数、GB 数、费用和计算依据 | `requestsPerMonth`，以及可选的 `linesPerRequest`（默认 4）、`provider`、`perGb`、`perMillionIndexed`、`keepPercent`（默认 100） |

`provider` 可选 `datadog`、`grafana`、`sentry`、`posthog`、`betterstack`、`axiom`。`estimate-log-cost` 使用的字节数和费率列在[日志成本](/reference/cost)页面。

## 向它提问

连接服务器后，在提示中点名使用它，让代理读取文档而不是猜测：

```text
Using the evlog MCP, read the Nuxt integration page and add evlog to this app.
```

```text
Using the evlog MCP, what does 10 million requests a month at 4 log lines each cost on Datadog, and with evlog?
```

## MCP、技能或 llms.txt

| 你希望代理 | 使用 |
| --- | --- |
| 在任务中查询某个页面 | 此 MCP 服务器 |
| 遵循 evlog 约定并审查日志代码 | 使用 `npx skills add https://www.evlog.dev` 安装的[代理技能](/reference/agent-skills) |
| 在不支持 MCP 的工具中阅读文档 | [`llms.txt`](https://www.evlog.dev/llms.txt)，或通过 `/raw/<path>.md` 获取任意页面的 Markdown |

服务器和技能可以配合使用：技能提供实践模式，服务器提供当前 API。

## 常见问题

::accordion{type="single"}
  ::accordion-item{label="需要 API 密钥或账户吗？"}
  不需要。服务器只提供公开文档，因此无需身份验证。
  ::
  ::accordion-item{label="它能读取我的代码或日志吗？"}
  不能。`list-pages` 和 `get-page` 只读取文档，`estimate-log-cost` 根据参数中的数字进行计算。工具不会接收其他输入。
  ::
  ::accordion-item{label="文档多久更新一次？"}
  `list-pages` 和 `get-page` 会缓存一小时，因此文档部署后最迟一小时就会更新到服务器。
  ::
::
