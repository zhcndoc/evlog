evlog 支持 Nuxt、Next.js、SvelteKit、Nitro、NestJS 以及任何 TypeScript 服务端框架。

::prompt

  - cursor
  - claude
---

将 evlog（https://www.evlog.dev）添加到此项目。

1. 运行 `npx --yes evlog init --yes`。它会检测框架，使用此项目的包管理器安装 evlog，写入 `evlog.config.ts`、接入框架集成，并将 evlog 规则添加到 `AGENTS.md`。完成它输出的所有手动步骤，并修复最终检查指出的问题。
2. 如果它报告框架不受支持，或无法运行命令，请安装 `evlog`，并按照 https://www.evlog.dev/llms.txt 中对应的框架指南操作。如果没有对应指南，服务端项目请使用 https://www.evlog.dev/extend/custom-framework；脚本和任务请使用 https://www.evlog.dev/integrate/frameworks/standalone。
3. 后续服务端代码中，每个请求都通过集成的 logger 生成一个宽事件，并使用 `log.set({ ... })`；用 `throw createError({ message, status, why, fix })` 代替 `new Error()`，不要使用 `console.log`。

::

## 安装

::code-group
```bash [pnpm]
pnpm add evlog
```
```bash [bun]
bun add evlog
```
```bash [yarn]
yarn add evlog
```
```bash [npm]
npm install evlog
```
::

### 使用 Agent 技能

如果你使用了 AI 助手（如 Claude Code、Cursor 等），安装 evlog 技能以获得引导式设置和代码审查：

```bash [Terminal]
npx skills add https://www.evlog.dev
```

你的 AI 助手随后可以帮助你设置 evlog、审查你的日志记录模式，并将现有代码迁移到宽事件。有关详细信息，请参阅 [Agent Skills](/reference/agent-skills)。

::callout{icon="i-lucide-radar" color="neutral"}
**试试 `evlog map`。** `evlog` 可执行文件随软件包提供。虽然还处于早期阶段，但只需一条命令即可评估哪些入口点仍然没有日志记录：

```bash
npx evlog map
# 或：pnpm evlog map
```

查看 [CLI 概览](/cli/overview) 和 [`evlog map`](/cli/map)
::

## 创建配置

运行 `npx evlog init`，或手动在应用根目录添加 `evlog.config.ts`：

```typescript [evlog.config.ts]
import { defineEvlog } from 'evlog'

export default defineEvlog({
  service: 'my-app',
})
```

这个文件包含所有选项：采样、drain、增强器和路由过滤器。对应的框架指南会说明如何加载它。请参阅[配置](/reference/configuration)。

## 为你添加的字段提供类型

evlog 附带完整的 TypeScript 类型定义，无需额外配置。

::callout{icon="i-lucide-check" color="success"}
evlog 需要 TypeScript 5.0 或更高版本以获得最佳的类型推断。
